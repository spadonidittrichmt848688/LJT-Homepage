# LJT-Homepage

Personal academic homepage for Junteng Liu, forked from [Academic Pages](https://github.com/academicpages/academicpages.github.io).

## Content

- `_pages/about.md`: biography, research interests and skills, education, research experience, publications, honors, and contact information.
- `_publications/`: publication metadata, using the recorded publication year.
- `_includes/publication-list.html`: shared publication listing displayed on both the About and Publications pages.
- `_config.yml`: site identity, contact links, and GitHub Pages settings.

## Local preview

Install the Ruby dependencies with `bundle install`, then run `bundle exec jekyll serve`.

The site is configured for `https://spadonidittrichmt848688.github.io/LJT-Homepage/`. The GitHub Actions workflow builds and deploys the site from `master`.
